# Dash Dashboard

An interactive data visualization dashboard built using Python, Dash, Pandas, and Plotly.

## Features
- Interactive scatter plot of population and GDP per capita
- Box plot for exploring GDP per capita distribution
- Dashboard layout using Dash HTML components

## Technologies Used
- Python
- Pandas
- Plotly
- Dash

## Dataset
Uses `gapminder.csv` for the visualizations.

## How to Run
1. Install Python.
2. Install the required libraries:
   `pip install pandas plotly dash`
3. Run the application:
   `python app.py`

## Learning Purpose
Created as a learning project to practice Python data analysis and dashboard development.
